# Регламент «Математических боев с ИИ»

Статичная страница без сборки: весь код, стили и логотип лежат в `index.html`.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub (например, `math-fight`).
2. Загрузите в корень репозитория файлы `index.html` и `.nojekyll`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Source: Deploy from a branch, ветку `main` и папку `/ (root)`, нажмите Save.
5. Через минуту-две страница появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.
